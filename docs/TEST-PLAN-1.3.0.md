## 6. 已知限制（不是缺陷，不必上报）

1. **B站 DASH 的在线预览暂不支持**（下载后合轨正常）——结果页这类条目不显示「预览」。
2. HLS（AcFun）预览**只支持 H.264 + AAC**；加密流（`EXT-X-KEY`）、`EXT-X-BYTERANGE`、HEVC 会提示无法预览。
3. HLS 预览的进度条只能拖到**已缓冲**的位置，向前拖动尚未下载的部分不会跳转。
4. 预览播放器不支持字幕/多音轨选择（各平台直链本身也不带这些）。
5. 迅雷 / 123 等网盘的转存与限额行为由平台决定，遇到「空间不足 / 限速」属正常提示。
